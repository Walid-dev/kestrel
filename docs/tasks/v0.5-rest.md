# v0.5 · The rest, and the old setup retired — the build plan

**Status: built, sweep pending.** Tasks with agent commands, deal searches riding the one engine, the models' costs,
and the morning brief are in. The retirement map is `docs/retirement.md`; each old part stops by its two-weeks rule.

## The steps

1. **Tasks** — migration 011; one line each, closing takes a short note of what was done, reopening keeps the words.
   Routes under `/api/tasks`; the screen (Enter adds; the note box opens on Close; done folds below); the agent
   commands `kestrel task-list | task-add | task-close | task-reopen`. The old Hub file carries over by id
   (`scripts/import-tasks.ts`, dry then write; the real run landed 45). Check: the domain's tests.
2. **Deal searches** — the same engine: `Item.price`, a spec's `price.cap` (under earns the pay part, over says so),
   and the kind decides identity — a job reposted under a new link is the same job (org|title), a deal is its link.
   The v1 import walks the old items too, vocabulary mapped onto the one status set (contacted→applied, not→passed,
   sold→closed), the 0–10 score onto the 0–100 card; the real run carried 426. Searches shows mirrored searches
   without a spec file as quiet cards; a search filter joins the others; a deal's card shows its price. The deal
   collectors stay in the old setup until cutover, mirrored nightly like the jobs.
3. **The models' costs** — `/api/models/calls`: every recorded call grouped by purpose and model, seconds each,
   failures named, on the Models screen. Local models charge time, nothing else.
4. **The morning brief** — plain sentences counted from the database: fresh great matches, the Priority count,
   applications waiting, lessons due, open tasks. `/api/brief`, shown on Home. A quiet morning says so.
5. **The retirement** — `docs/retirement.md`: the map from each old part to its new home, the two-weeks rule, and
   the cutovers that wait for me.

## Out of scope

Chats inside kestrel; new deal collectors in the repo (site scripts are personal and fragile — they stay in the data
folder); price history charts (the old setup keeps the history until its retirement).
