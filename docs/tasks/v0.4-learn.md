# v0.4 · Learn and Interview — the build plan

One Learn app absorbs the old setup's two (decided 2026-11-20): Learn's lesson shape — say, explain, example, words,
check — written in the plain style, one lesson per page, read aloud, with Ask on every lesson; packs make prepared
answers, lessons and check questions one kind of content. The engine lives in the repo; the lessons are mine, so the
content lives in the database and the data folder, seeded made-up in dev.

## The steps

1. **The content model** — migration: `packs` (id, name, kind: lesson-pack | answer-pack) and `lessons` (id, pack,
   position, title, body JSON in the lesson shape: say[], explain[], example, words[{w,m}], check[{q,a}]). One shape
   serves lessons, prepared answers and demo scripts — a prepared answer is a lesson whose say lines are the answer.
   Check: shape tests; a made-up dev pack seeds the screens.
2. **The reader** — one lesson per page: the say lines first and large, then the explanation, the example, the words,
   the check (answers folded until asked). Search across lessons; previous/next inside a pack. Check: phone and
   computer widths in the browser.
3. **Listen and Follow** — the computer reads the lesson line by line with the device's own voice (Web Speech, fully
   local) and lights the line it says; tap a line to read from there; the switch keeps the design system's voice.
   Check: proven by hand in the browser (voices vary by device, so the test is the switch and the highlight).
4. **Ask, with its eval first** — the question, the open lesson and the pack's map go to the picked model through the
   one client; the answer comes back shaped (answer, and which lessons it drew on). The eval's made-up cases are
   written before the feature and run on the stand-in inside the check; a live run on both models lands in docs/eval
   before first use. The Models screen gains the learn-ask use.
5. **Practice, spaced** — `reviews` (lesson, due, interval, ease): the check questions come due on a simple spaced
   rhythm (again → tomorrow, good → interval grows); the Practice screen asks what is due and grades move the due
   date. Check: the rhythm's table with a fake clock.
6. **Live** — hold to talk: the phone records, kestrel forwards the sound to the local ASR model (the door already
   lists one), and the nearest prepared answer shows large. Nothing leaves the computer. Check: the matcher's tests
   with made-up questions; the mic path by hand.
7. **The import** — `node scripts/import-learn.ts --from <the old apps folder>` carries the old Learn lessons and the
   guides into packs (dry run with counts, then write). Check: a made-up old folder converts; the real run at my
   machine.
