# v0.9 · The design system — the proposal

**Status: planned (2026-11-23), after v0.8.** Nothing here is built yet.

## The problem

[docs/design.md](../design.md) set one look on 2026-11-20: the tokens, `.btn`, `.card`, chips. The pages grew since,
and each new part was styled where it was needed: the segmented choice, the big tiles, the Ask box, the drawings,
the list card with its ✕, the Stop choice. Many pages still set colours and sizes inline. The look holds, but by
care, not by structure: a new page copies an old one, and two pages drift apart.

## The proposal

1. **The tokens in one file**, named by role: the ground, the ink, the lead colour, the working colours, the type
   scale, the spacing, the radii. Light and dark from the same names.
2. **One component library** in `web/src/ui/`: the page head (eyebrow, title, the line under it, its actions),
   Button (primary, quiet, danger, big), Card (plain, link, with a ✕), Chip, Seg (the segmented choice), Tile,
   Field (a text box that sends on Enter, with its send button), Sheet (a native dialog), EmptyState, and the
   drawings (already one renderer since v0.8). Each takes a few props, never a style.
3. **A page that shows every part**, `/design`: each component in its states, in both themes, at a phone's width and
   a computer's. The review of a new part happens there first.
4. **The pages move one at a time**, Learn first (the look the others follow), each checked at both widths in a real
   browser. Inline colours and sizes go; what a page needs that the library lacks becomes a part of it.
5. **A check that names a one-off**: an inline style with a colour or a size outside `web/src/ui/` fails the check,
   with the component to use instead.

## The steps

1. The tokens file and `/design` with today's parts as they are.
2. The library's first parts (page head, Button, Card, Chip, Seg, Field), each shown on `/design`.
3. Learn, then Searches, Notes, Writing, Research, Live, Tasks, the quiz, Home, moved one page per change.
4. The check, once the pages are moved.
